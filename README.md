# Sistema de Gestión de Personal mediante Árboles BST 

Este repositorio contiene la implementación de un sistema de gestión jerárquica empresarial desarrollado en C++. El proyecto utiliza estructuras de datos no lineales para optimizar la organización y administración de personal.

##  Descripción del Sistema
El sistema permite modelar el organigrama de una empresa donde cada empleado es un nodo dentro de un **Árbol Binario de Búsqueda (BST)**. La jerarquía se determina mediante el código de identificación del empleado, permitiendo búsquedas e inserciones con una eficiencia logarítmica.

##  Requerimientos del Proyecto
Para el correcto funcionamiento y validación del sistema, se han implementado los siguientes requerimientos técnicos:

1. **Gestión de Datos:** Inserción dinámica de empleados (Código, Nombre, Cargo) asegurando la unicidad de las claves.
2. **Visualización Jerárquica:** * **Recorrido Inorden:** Generación de reportes administrativos ordenados por código.
    * **Recorrido Preorden:** Mapeo de la estructura de mando (superior a subordinado).
    * **Recorrido Postorden:** Implementación lógica para la liberación de memoria.
3. **Análisis Estructural:** * Identificación de la **Raíz** (Dirección General).
    * Cálculo automático de la **Altura** (Niveles jerárquicos).
    * Detección de **Nodos Hoja** (Personal operativo sin subordinados).
4. **Interactividad:** Interfaz de consola mediante menús dinámicos y validación de entrada de datos.
